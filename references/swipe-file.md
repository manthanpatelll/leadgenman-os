# Swipe File

Structure notes on reels I found instructive. Format only: creator, format category, the hook frame as a fill-in-the-blank, why the structure works, and how I'd run the same shape with my own material. I never reuse anyone's words, artwork or list. Formats are free, content isn't.

## How I use this file

- Read the madlib, not the reel. The frame is the reusable part.
- Fill it with my own topic, my own screen, my own proof.
- Run it through the winning-patterns filter before building.
- If the adaptation still sounds like the original, it's too close. Change the substance until it's mine.

## Entry 1

| Field | Note |
|---|---|
| Creator | @bradfordmarais |
| Format | Educational tutorial, talking head cut with full-screen terminal recordings |
| Hook frame | "[Tool] just changed how you [common task] forever. Give me [N] seconds and I'll show you how." |
| Angle | A personal AI operating system that runs your existing method, not a generic writer |

**Why it works.** The hook time-boxes the ask, which lowers the cost of staying. Face and terminal alternate every few seconds so a long explainer keeps moving, and the terminal footage proves the system is real rather than slideware. A caveat beat near the end ("it structures, it doesn't replace your ideas") makes the whole thing feel honest.

**How I'd adapt the format.** Same frame, my operating system. Show my own folder structure, my own slash commands and a real reel script coming out the other end for PenAnywhere or TiltIt. The proof is my own published reel made with the system. Keyword CTA instead of a follow ask.

## Entry 2

| Field | Note |
|---|---|
| Creator | @lukesbrave |
| Format | Educational tutorial, over-the-shoulder workflow walkthrough |
| Hook frame | "I have [high-value outcome] running [process condition]. I don't even [common time-consuming action], guys." |
| Angle | Treat your internal content workflow as a product demo |

**Why it works.** The hook is a contrarian flex that doubles as proof: claiming not to do the obvious chore only lands if the output is visible, and it is, immediately. A "no slop" reassurance beat handles the biggest objection to automated content before the walkthrough starts. The long screen tour rewards the viewers who stayed with real steps.

**How I'd adapt the format.** My carousel pipeline. Open on a finished carousel of mine already live, state the condition it ran under, then walk the real steps in my own tools. The differentiator is design quality: I'd show the Finder-style carousel output so the "no slop" beat is visible, not spoken.

## Entry 3

| Field | Note |
|---|---|
| Creator | @vishakha.sadhwani |
| Format | Educational listicle, green-screen with icon pairs |
| Hook frame | "[Tool A] and [Tool B] are [adjective], but together they make [result]." |
| Angle | Frame tools as pairs that unlock a higher-level outcome |

**Why it works.** One sentence structure repeated for the whole runtime. The viewer learns the pattern in the first four seconds and then predicts the rhythm, which is what keeps a rapid-fire list watchable. The turn ("but together they make") carries the whole format, and each payoff is a concrete system rather than a vague benefit. Icons landing exactly on the spoken name keep the visual and audio hooks aligned.

**How I'd adapt the format.** This is my 2-ingredient collision formula in list form. Pair Claude Code with the tools I've actually shipped with and name the thing each pair produced: an App Store app, a paid product, a daily newsletter. Every pair is one I can prove with a live link, which is the part nobody else can copy. Keep it to five pairs and under 30 seconds.

## Entry 4

| Field | Note |
|---|---|
| Creator | Cova |
| Format | Reels-native AI coding content, Claude Code plus a note-taking app as a content pipeline |
| Hook frame | "[AI tool] + [everyday app] = [content output] on autopilot" |
| Angle | The pipeline itself is the content |

**Why it works.** Most AI coding coverage lives on YouTube, so a creator who is Reels-native in this niche has very little competition. Pairing a coding tool with a familiar everyday app gives the reel two audiences at once and a searchable keyword. It's the dual-audience mechanic behind my own collision formula.

**How I'd adapt the format.** Claude Code plus Descript, or Claude Code plus Beehiiv. Show my real newsletter or reel pipeline end to end with a finished piece as the proof, and be explicit about the one step where I still make the call by hand. That honesty beat is what separates it from an automation pitch.
