# Winning Patterns

The reel and carousel structures I reuse. Each one has a beat map with rough timings and the reason each beat exists. These are templates. The substance inside them is always new.

## Why I only build top-20% reels

My last 100 reels confirmed Pareto inside Pareto: the top 1% drove about 12% of views, the top 4% about 37%, the top 20% about 68%. The bottom 80% combined was about 32%. Posting more average reels is donkey work. Every concept runs this filter first:

1. Pattern-matches a top-tier topic? If no, kill.
2. Hook fits a winning archetype? If no, kill.
3. Keyword DM CTA in the caption with curly quotes? If no, add.
4. Tool collision or "stop paying" angle? If no, ask if it can be.

Fails two or more, don't build it.

## Pattern 1: The 2-ingredient collision (A-tier)

Claude Code + [specific named tool] + contrarian or shipped-proof hook. Proven twice in a row: Claude Code + App Store (paid iOS app PenAnywhere, live listing as proof) and Claude Code + Google Stitch ("Claude Code is a terrible designer", side-by-side output as proof).

| Time | Beat | Why it works |
|---|---|---|
| 0 to 3s | Two-line hook naming both tools, contrarian or proof claim | Two ingredients is an unexpected collision. One ingredient gets skipped. |
| 3 to 8s | Show the live result first (App Store page, real output) | Proof before explanation. Viewer now believes the claim. |
| 8 to 20s | The how, in two or three tight steps on real screen | Tactical value, this is what gets sent to a friend. |
| 20 to 25s | The catch or the twist | Honesty beat, stops it reading like an ad. |
| Last 3s | Keyword CTA, spoken and in caption | +48% lift. Non-negotiable. |

Second-tool candidates I've actually shipped with come first: App Store, Xcode, Stripe, Vercel, Supabase, Descript, n8n. Then competitors and platforms: Cursor, Codex, Figma, Stitch, Notion, TradingView.

## Pattern 2: New feature launch coverage

Reliable, not viral. A Claude or Claude Code feature drops, I ship a reel that day.

| Time | Beat | Why it works |
|---|---|---|
| 0 to 3s | "[Feature] just dropped. Here's what it does." | First-mover on a topic the beginner audience hasn't seen. |
| 3 to 15s | Real demo, real terminal | Proof it exists and works. |
| 15 to 22s | One concrete use case I'd run it for | Turns news into something usable today. |
| Last 3s | Keyword CTA | Same rule. |

The window closes fast. Watch the changelog and release notes.

## Pattern 3: Netflix swap

"Instead of [common time-waste], do [specific tool play]."

- 0 to 2s: name the time-waste, cut hard to the alternative.
- 2 to 12s: show the tool play running, no setup talk.
- 12 to 15s: the result and the keyword.

Works because it reframes an existing habit rather than asking for a new one.

## Pattern 4: The bracket

"[Tool A] vs [Tool B]." Each matchup gets one task, one visible output, one winner. Three matchups in 20 to 30 seconds. Opens directly on matchup one, never on a previous bracket's winner.

## Pattern 5: Stop paying

"Stop paying [$N for service], use [free alternative]." Lead with the dollar figure, show the free thing doing the same job on screen, close with the setup keyword. Self-host and open-source angles are my single biggest topic tier.

## Pattern 6: Credibility build

"I've used [tool] for [time]. Here's [setup]." 15 to 45 seconds. Screen recording of the real setup, no slides. The time claim is the authority hook, the setup is the DM-able asset.

## Pattern 7: Cinematic surprise

7 seconds, no setup, one visual punch. Built for cold reach. Everything on frame zero, punch by second two, hold to the end.

## Pattern 8: Humour escalation (own work)

From my "boyfriend material" workflow reel. Safe to reuse as a template because it's mine.

| Time | Beat | Why it works |
|---|---|---|
| 0 to 4s | Relatable pain in one line | Everyone recognises the situation instantly. |
| 4 to 9s | Feature 1, mildly absurd | Establishes the joke's logic. |
| 9 to 14s | Feature 2, more absurd | Escalation keeps the watch going. |
| 14 to 22s | Feature 3, the most absurd, ideally an AI clone angle | The share moment. This is the beat people send. |
| 22 to 25s | Payoff line that names the outcome | Ties the three features into one memorable phrase. |
| Last 3s | "Want it? Comment [keyword]." | Keyword CTA. |

Rule of three, absurd last beat, keyword close. Works for any automation topic.

## Carousel structures

| Structure | Slides | Shape |
|---|---|---|
| Setup / folder tour | 8 to 12 | Cover with real interface chrome, one folder or file per slide, CTA slide |
| Prompt list | 10 to 12 | Cover states the count, 5 to 6 prompts per slide in a chat-style mockup, CTA slide |
| Learning roadmap | 10 to 15 | Winding path, numbered stops, one stage per slide, seamless across boundaries |
| Step-by-step editorial | 8 to 10 | Alternating light and dark slides, step pills, big watermark numbers |
| Resource curation | 8 to 10 | Icon grid cards, one category per slide |

Design families in order of proven quality: Finder/Folder (gold standard), VS Code mockup, claude.ai dark, editorial step-by-step, Safari plus wallpaper, seamless roadmap. Film strip flopped. 17 slides flopped.

Every carousel: 8px Swiss grid, 60-30-10 colour rule, cream background, multi-layer shadows, CTA slide with keyword in curly quotes, 500+ word caption, no hashtags.

## Universal rules across every pattern

- Hook first, everything else second. If the hook doesn't work, the concept dies.
- Real result on screen. Live URL, real listing, running agent. Never a mockup.
- Only things I can say. My shipped products, my audience, my setup.
- Standalone. No sequel callbacks.
- Frame zero fully drawn, no fades, payoff held for at least a quarter of the runtime.
