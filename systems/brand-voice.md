# Brand Voice

How I sound when I talk on camera and how the words on a slide should read. Every script, caption, carousel and newsletter line runs through this file.

## The voice in one paragraph

I talk like I'm on a phone call with a friend who asked me how I built something. Plain words, contractions everywhere, a bit of broken English is fine because that is how I speak. I say "doubt" not "question". I speak to "you", never to "the user". I move forward the whole time and I never restate a point I already made.

## Core rules

- Conversational. Contractions in every sentence where they fit: I'm, you'll, it's, don't, that's.
- Second person. "You can connect it" not "the user can connect it".
- Grade 5 to 6 readability. Break any sentence over 20 words.
- Forward momentum. Each line adds a new piece. Never restate the hook inside the body.
- Combine features into one flowing sentence with "and", "or", "nor" instead of stacked commas.
- Open body beats with So, Then, Now or But. Never open the hook that way.
- "So" as a sentence starter: maximum two per script, body or CTA only.
- The strongest transition is usually a full stop and the next idea.
- Never repeat a connector across one script. Rotate adding, sequencing, cause and effect, emphasis, example.

## Sentence rhythm

Alternate lengths. Never two of the same length in a row.

| Length | Words | Job |
|---|---|---|
| Short | 5 to 8 | Land a point |
| Medium | 12 to 18 | Explain the step |
| Long | 20+ | Connect two ideas, then break back to short |

Every sentence is full and pronounceable. No staccato fragments like "Done." or "It's huge." Never a three-word dramatic line like "It gets worse."

## Hook rules

- Two lines maximum.
- Keep the structure, word count and emotional pull tight.
- Never add a second claim to a hook.
- Never start a hook with So, Now, Here's.

## Banned phrases

Scan every draft before it ships. Any hit means rewrite that line.

| Banned | Why |
|---|---|
| "Here's where it gets [adjective]" | Filler bridge |
| "No X. No Y. Just Z." and any 3-part negative list | Templated rhythm, I hate it |
| "wildest" or "wildest part" | Overused hype word |
| "and that's it" or "that's it" as a closer | Weak ending |
| Rhetorical question pauses like "Next morning? Slack is flooded." | Fake drama |
| "Now here's what I did" | Meta narration |
| Numbered step formats like "Step 1" or "First, Second, Third" | Reads like a manual |
| Em dashes and double hyphens | Not how I write, use a comma or a full stop |
| "Here is why this matters" and every variation | Filler bridge |
| "Why this is interesting" or "and that's the crazy part" | Filler bridge |
| Three-word dramatic punch lines | TikTok cadence, not substance |
| "if you have any doubts" in a CTA | Weak value frame |
| "link in bio" | Never, the DM mechanic replaces it |

## Written to spoken swaps

| Written | Spoken |
|---|---|
| utilize | use |
| navigate to | go to |
| configure | set up |
| subsequently | then |
| furthermore, additionally | and, plus, on top of that |
| for example | like, say you're |
| digs through | goes through |
| hand-searching | hunting for |
| extract | pull |
| leverage | use |
| in order to | to |
| question | doubt |

Anything that sounds like Wikipedia gets rewritten.

## AI slop to kill

- Vague catch-alls like "or any of that" or "all that stuff". Name the specific thing.
- Generic AI comparisons with no example. Name it, like "that default purple gradient AI look".
- Inflated fillers like "This is the big one". Cut.
- "All the little things that make X feel Y". Name the things or stop.
- Polished similes like "works like an actual senior engineer who never sleeps". Say the plain action.

## CTA format

- comment [WORD] and I'll send it straight away in your DMs
- Frame the reason as value: the full steps, the prompts, the repo link.
- One trigger word, one CTA, never stacked.

## Good vs bad

| Bad | Good |
|---|---|
| Here's where it gets crazy. | Then the agent opened my calendar on its own. |
| No code. No setup. No team. | I didn't write a single line of code for this. |
| Step 1, install the CLI. Step 2, run init. | Install the CLI and run init, it takes about a minute. |
| Two million devices. Already infected. | Two million devices already had it installed before anyone noticed. |
| Next morning? Slack is flooded. | By the next morning my Slack had forty messages about it. |
| Utilize the skill to navigate to the config. | Use the skill and go to the config. |
| The user can configure the hook subsequently. | Then you set up the hook. |
| If you have any doubts, link in bio. | If you want the full setup, comment HOOKS and I'll send it straight away in your DMs. |
| And that's it. | Now every commit runs the check before it lands. |
| It works like a senior engineer who never sleeps. | It reads the error, fixes the file and reruns the test. |

## Final check before shipping

1. Read it out loud once. If I would not say it on a call, change it.
2. Run the banned phrase scan.
3. Check no two sentences in a row share the same length.
4. Confirm the CTA has one keyword and a value reason.
5. Confirm no em dash, no double hyphen, no emoji I did not ask for.
