# Archives

Everything that has already gone live moves here, so the working folders stay clean.

## What gets archived

- Carousels from `content/carousels/` once they are posted, with the final caption and post date added at the top.
- Hook batches from `/hooks` that produced a winner. The losing hooks stay too, they are useful for the next rubric pass.
- Old versions of `strategy.md` and `current-data.md`, one snapshot per month.

## Naming

```
archives/carousels/2026-09-18-claude-code-slash-commands.md
archives/hooks/2026-09-20-ai-tools-i-pay-for.md
archives/snapshots/2026-09-current-data.md
```

Date first, then the slug. Never rename a file after it lands here.

## Rules

- Archive after posting, never before approval.
- Add the real post link and the first 48 hour numbers when I have them.
- Nothing in here gets edited, it is the record.
