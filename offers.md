# Offers

Every offer I run, what it costs, who it is for, and how to plug it. When a script or carousel needs a CTA, pull from here.

## The CTA mechanic

All my content CTAs use one mechanic: the viewer comments a keyword, I send the link in their DMs.

- Format: comment [WORD] and I'll send it straight away in your DMs
- The reason is always value: the full steps, the prompts, the repo, the template. Never "if you have any doubts".
- One keyword per piece. One CTA per piece. Never stack two.
- Never say link in bio. Never say DM me without a trigger word.
- If the source format had no trigger CTA, add one anyway.

## Which offer to plug per content type

| Content type | Primary plug | Keyword style | Backup plug |

| Lead gen or cold email reel | Skool community | Tool name, like CLAY or APOLLO | Tool affiliate link |
| AI news reel | Newsletter | NEWS or BRIEF | None |
| Screen recording tutorial | TiltIt or PenAnywhere | TILT or PEN | Skool community |
| Sponsored reel | Sponsor's link | Sponsor's keyword | None, brand deal stays clean |
| LinkedIn carousel | Skool community | Keyword in the last slide | Newsletter |
| YouTube long video | Skool community in first link slot | Spoken CTA plus description link | Affiliate links per tool |
| Threads text post | Newsletter | Reply with keyword | Skool community |

## Rules

- Skool community is the default plug. When unsure, plug it.
- Never call the community free. Never hide the price.
- Never stack more than one offer in a single reel.
- Sponsored pieces never plug my own offers unless the brand agrees.
- Every plug frames the value first, then the mechanic.
